# Tattoo - Inkpulse Luxury Tattoo & Body Piercing Atelier

A luxury, bespoke website for Inkpulse Tattoo & Body Piercing Atelier. Built with modern semantic HTML5, Tailwind CSS, Obsidian & Gold luxury aesthetic, authentic client reviews, and a 16-piece portfolio.

## ✨ Features
- **Hero & Brand Presence**: High-impact luxury studio atmosphere.
- **Bespoke Portfolio**: Categorized works across Micro-Realism, Black & Grey, Sacred Geometry, Japanese Irezumi, and Titanium Body Piercing.
- **Client Reviews**: Alternating reviews featuring authentic client tattoo artwork.
- **Aftercare Protocols**: Comprehensive medical-grade healing guidelines.
- **Consultation Booking**: Interactive booking modal with style selection and date scheduling.
